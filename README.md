# ArchiTrac

All-in-one practice management for small architecture firms.

## Start here
1. **Getting started guide**: the step-by-step setup, at https://claude.ai/artifact/6He6fY4AoBGDb8Ah8QnVC8 (a copy is in `docs/GETTING_STARTED.md`).
2. `CLAUDE.md` — rules Claude Code follows in this repo.
3. `docs/ROADMAP.md` — what's being built, in order.
4. `docs/PROMPTS.md` — the prompts to give Claude Code for each milestone.

## What's in this kit

| Path | What it is |
|---|---|
| `CLAUDE.md` | Project instructions Claude Code reads every session |
| `docs/ARCHITECTURE.md` | Stack, folders, multi-tenancy, permissions, environments |
| `docs/DATA_MODEL.md` | Every table and column, plus the core calculations |
| `docs/DESIGN_SYSTEM.md` | Colors, type, components, formatting rules |
| `docs/ROADMAP.md` | Releases 0–5 and the milestones for 0 and 1 |
| `docs/OPEN_DECISIONS.md` | Decisions you need to make, with recommendations |
| `docs/PROMPTS.md` | Copy-paste prompts for Claude Code |
| `docs/specs/` | One spec per screen (Release 0, 1, and the Release 2 snapshot math) |
| `docs/decisions/` | Architecture decision records |
| `src/styles/tokens.css` | Design tokens for Tailwind |
| `mockup/` | Source of the mockup pages, for Claude Code to read. View the rendered mockup at https://claude.ai/artifact/F7g4PL5cpRbcxRK9RRKggs |
| `seed/` | Demo data that matches the mockup |
| `.env.example` | List of the keys and settings the app needs |
